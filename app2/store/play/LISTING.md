## 完整說明

```
趕快找到你附近的廁所！急廁 Go 用地圖找出離你最近、還在營業的地點，一鍵導航過去。

【免費】
・全台 7-11（線上載入）
・地圖顯示附近營業中地點
・投票留言、一鍵導航
・無需註冊帳號

【完整資料包（一次性買斷）】
・解鎖公廁、全家、加油站、路易莎、星巴克、寶雅、百貨、捷運等
・下載後可離線使用
・支援恢復購買

【怎麼用】
1. 開啟 App，允許定位
2. 地圖顯示附近地點；可切換「附近／全部」
3. 右上角「解鎖」可買斷並下載完整資料包
4. 點地點可導航、投票、留言

本 App 需定位與網路（首次下載資料包時）。留言需連線同步。
```
