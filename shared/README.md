# Shared Workspace

This folder is the handoff zone between SuperGrok and Grok Bots.

- **SuperGrok** writes drafts, strategies, task briefs here.
- **Bots** pull and execute (post, implement, scan, etc.).

## Structure
- `drafts/` — post / script drafts ready for bots
- `tasks/` — task instructions for specific bots
- `calendar/` — posting or release calendars
- `strategy/` — short-term strategy notes

Do not commit secrets.
