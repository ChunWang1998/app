目標客群：中老年人。產品以群組共抄為核心，學習輔助與分享為加值。

## 經文來源與離線全庫（已實作架構）

### 目標

- **離線也要全 CBETA 集成**（約 4,868 部、2.2 億字級；發布包約 0.5～1 GB 壓縮正文）
- App **安裝包內只帶精選入門包**；全庫 **裝後下載**（設定頁）
- 執行時 **按需讀一句**，不把全文塞進記憶體

### 已拍板技術決策

| 項目 | 決定 |
|------|------|
| 經文 ID | **CBETA 純文字 `work_id`**（如 `T0251`）；XML 式 `T08n0251`／舊房間 `heart` 透過 alias 對應同一部 |
| 單元 | 句（`。！？；` 切分；偈頌需從 CBETA 結構另處理） |
| 打包 | **每經一檔** `units/{workId}.json` + `catalog.json` + `manifest.json`（支援增量更新） |
| 版本號 | 跟 CBETA 發行（如 `2026R1`）；入門包 `2026-starter-1` |
| 入門包 | 10 部精選節錄 + 注音，內建於 `assets/corpus/starter/` |
| 全庫注音 | **不預打包**；入門包注音；全庫僅正文（P4 可選本機引擎或第二下載包） |
| 儲存 | 入門：`require` 內建 JSON；全庫：`expo-file-system` 文件目錄 `cbeta/full/` |
| 目錄搜尋 | 合併入門 + 已安裝全庫 catalog（後期可加 SQLite FTS） |
| CDN | `EXPO_PUBLIC_CORPUS_CDN_BASE` 指向部署目錄（R2 + Cloudflare 建議） |
| 建置 | `app3/tools/cbeta-build`：`build:starter` / `build:full` |
| 房間進度 | 仍只存 `sutraId` + `unitId` 整數，與庫大小無關 |

### 建置與部署

```bash
# 入門包（隨 App 發布）
cd app3/tools/cbeta-build && npm run build:starter

# 全庫（部署到 CDN，不進安裝包）
# 1. 將 CBETA 純文字放入 tools/cbeta-build/input/txt/
# 2. CBETA_VERSION=2026R1 npm run build:full
# 3. 部署 app3/corpus-dist/full/ 到 CDN
# 4. mobile/.env：EXPO_PUBLIC_CORPUS_CDN_BASE=https://…/2026R1
```

### R2（Cloudflare）上傳/測試紀錄（2026-08-12）

- `wrangler r2 object put ...`：一開始因本機 macOS 版本太低（wrangler 要求 >= 13.5）導致失敗；改用 `rclone`
- `rclone` remote 設定：
  - remote 名稱：`sutracopy`（type = `s3`）
  - provider：`Cloudflare`
  - endpoint：`370e167ac699a8b1411a80b61541acb9.r2.cloudflarestorage.com`
  - `force_path_style = true`
- 常見錯誤與修正：
  - 400 `BadRequest: HeadObject`：原因是目的地路徑寫法錯誤；必須在 remote 後第一段寫 bucket 名
  - 正確目的地：`sutracopy:sutracopy/...`
- 小測試（成功）：
  - `rclone copy .../manifest.json sutracopy:sutracopy/manifest.json`
- full 同步（已開始；約 12%：~124MiB / ~1.034GiB）
  - `rclone sync ./../../corpus-dist/full/ sutracopy:sutracopy/ --progress --verbose --transfers 1`

### 成本粗估（100 次全量下載／月）

## 群組共抄（核心）

- 首頁以群組／房間為主，最多 5 人；**每人最多 3 個房間**
- 房間用 room id／房間碼進入；可開房或輸入碼進房；可選一篇一起抄
- 顯示個人進步、每日進度、成員是否達成當日目標（打開 App 時刷新）
- 群組內可分享「已抄完什麼」（文字＋深鏈）
- **積分／分數：不進 MVP**
- LINE：v1 用系統分享（文字＋深鏈）；精確選群發圖文可後期接 LIFF

## 主題短片／動態卡分享（群組內、依當日主題客製）

- 依「每日進度主題」客製，不是任意生成式長片
- 群組成員各自可輸入一點短文／提示，套用與當日主題相關的內容並分享在群組內
  - 例：今日主題是「羊」→ 家人各寫短文，各自產出與羊有關的短動態卡
- 必須打開 App 才能觀看（深鏈進 App 播放頁）
- 不需保存：即用即看／即分享，不做長期典藏與相簿
- **實作方向（已定：A）**：主題預製模板（Lottie／短 mp4）＋用戶短文案疊加；不呼叫 AI 文生影片
- **MVP**：不做 AI 生成影片；第一版若做分享，僅模板動態卡／圖文（可排在抄寫閉環與房間之後）

## 定時提醒／動畫

- **早上固定推播（如 5 點）：不進 MVP**
- 點開 App 後播放短動畫（Lottie 等）：可後期做；不依賴鎖屏直接播動畫
- 動畫為系統預製、全員相同（可依當日主題換檔）；不按人生成

## 抄寫體驗

- 預設字要夠大，可調小
- 支援平板（雙欄：左經右抄）
- **MVP：以「句」為單元，大按鈕點選完成**；非手迹筆畫擷取
- 左右手模式：工具列／操作區可左右鏡像（可後期）
- **手迹筆畫擷取（利於匯出手迹 PDF）：明確延後，非 MVP**

## 學習輔助

- **注音：抄寫頁開關可選（已做）**；精選入門包附注音；偏好本機保存
- 常見名詞解釋；邊抄邊看意思（點詞側欄；內容宜精編，宗教文本慎用未審 AI）
- 詞釋排在單人抄寫與房間共抄之後

## 進度安排

- 每日配額由**房主**設定；預計完成日；漏抄＝**補抄**
- UI 需極簡清楚

## 匯出

- 手迹筆畫 → 分頁圖／PDF：**非 MVP**（待有筆畫擷取再做）
- 若 MVP 需要「帶走成果」：可先做完成進度的文字／簡單圖卡系統分享；精緻 PNG／PDF 閱讀器不做

## 建議開發順序（依已拍板調整）

1. Expo 專案骨架＋首頁（開房／進房，免登入房間碼）✅
2. 單人／房內抄寫閉環（精選經繁體、大字、句單元、點選完成；平板雙欄）✅
3. 房間共抄（最多 5 人、房主每日配額、成員清單、打開 App 刷新進度、補抄、分享連結）✅
4. **離線佛典庫架構（入門包 + 全庫下載骨架）** ✅
5. 全庫建置／CDN 部署、P3 增量更新
6. 學習輔助（詞釋、進度表）；全庫注音策略
7. 增長（LINE 友好系統分享；積分不做）
8. （後期）儀式感（本地推播＋App 內動畫）
9. （後期）手迹筆畫擷取＋PNG／PDF 匯出；可選主題模板動態卡（非 AI）
10. （非 MVP）AI 生成影片／文生影片 — 明確延後
