# 寵物交友 MVP

## 定位
本地狗主人找附近狗主人：1 對 1 戶外見面，讓兩隻狗互相認識。

第一版只做**主人 ↔ 主人**。平台負責「找得到對的鄰居」；**訂閱後雙方自己約、自己處理**，不做代遛、不做一起遛行程、不做場次託管金流。

## 角色
單一角色：**狗主人**。上架狗檔案、搜尋附近主人、發出／接受邀約、聊天。

> v2 再考慮：幫忙遛狗（代遛）。一起遛狗（行程卡）不做。

---

## 產品原則（MVP）

1. **找得到對的人**比功能多更重要：地圖／列表、公園重疊、體型／個性篩選。
2. **訂閱後自己處理**：平台不追蹤進行中路段、不託管每場付款、不強制結束回報才能繼續用。
3. **安全用規則卡＋解鎖集合點**：精確位置與聊天在雙方同意後才開；現場怎麼走由雙方決定。
4. **不是動態牆**：沒有公開動態、沒有群組遛。

---

## 核心流程 — 狗狗交友

讓主人搜尋**附近有狗的主人**，約 1 對 1 戶外見面。重點是配對與溝通，不是行程管理。

### 探索（搜尋附近主人）
地圖＋列表，預設以自己定位／常用公園為中心。

| 篩選 | MVP |
|------|-----|
| **距離／區域** | 附近列表＋簡易地圖；模糊到商圈／公園，不露住家 |
| **常用公園重疊** | 雙方都標同一座公園的排前面 |
| **體型** | 小型／中型／大型；體型差兩級要警示（大狗嚇到小狗） |
| **個性** | 友善／怕生／活力高／慢熱／高齡／幼犬 |
| **能否與其他狗互動** | 可一起玩／需慢熱牽繩平行走／不適合（後者不可出現在交友搜尋） |
| **開放時段** | 今天／本週末／自訂 |
| **信用門檻** | 搜尋可看；發起邀約需達門檻（且需有效訂閱） |

個人頁／狗檔案在搜尋結果只顯示：狗照片、名字、品種／體型、個性、常用公園、信用摘要。精確集合點要等邀約被接受。

### 邀約與之後（平台到此為止）
```
搜尋附近主人
  → 看狗檔案
  → 提出見面（選公園＋時段＋15／30 分建議）
  → 對方接受
  → 解鎖集合點＋簡易聊天
  → 雙方自己約細節、自己見面、自己善後
```

建議預設文案（非強制行程）：**公園平行走 15 分鐘**（兩狗牽繩、保持距離）→ 雙方覺得 OK 再靠近。第一次不當成「放繩對玩」。

平台**不**做：進行中狀態機、GPS 軌跡、結束必傳照片才解鎖、每場 LINE Pay。可選：見面後互評／上傳現場照（加信用，非硬門檻）。

---

## 狗檔案（MVP 欄位）
- 名字、照片、品種／混種、體型、年齡區間
- 個性標籤：友善／怕生／活力高／慢熱／高齡／幼犬
- **與其他狗：** 可一起玩／需慢熱平行走／不適合交友
- 生效中的規則卡勾選結果
- 可否合照（預設可，主人可關）
- 所在商圈／常用公園（模糊到區域，精確點確認後再給）
- 開放時段

---

## 規則卡（建議＋勾選，不當場監控）

主人發布檔案時勾選生效項；詳情頁給對方看。現場遵守靠雙方，違規靠檢舉／信用。

- 雙方主人必須全程在場
- 第一次必須公共公園；不可約私人庭院／室內
- 全程牽繩，直到雙方口頭同意才可縮短距離
- 體型／年齡差大：預設平行走，不互相撲
- 任一方狗出現壓力訊號（躲、吠、低吼、身體僵硬），立即拉開距離並結束當次
- 攻擊／易受刺激紀錄必須在檔案標示；標示者不可出現在「可一起玩」篩選
- 不可進入電梯／私人空間（除非主人明確允許且已驗證）
- 不可餵食（除非主人勾選「可餵指定零食」）
- 先讓狗聞手／互相聞，再決定要不要靠近
- 不可臉貼臉、強抱、抓耳朵／尾巴
- 合照需當下口頭同意；夜間不可閃光燈直射眼睛
- 上傳照不可含他人正臉（除非已同意）；不可用於商業用途

---

## 信用分數

完成見面後**可選**上傳照片＋互評（不擋繼續使用）：

**加分**
- 準時、完成見面（雙方點「已見面」或互評即算）
- 上傳現場照（簡單審核：戶外、有狗、無違規）
- 對方給正面評價

**扣分／凍結**
- 放鳥、遲到嚴重、違規解繩／強行靠近對方的狗、未經同意拍照／傳播
- 被檢舉且成立 → 扣分；嚴重則暫停邀約權

**展示**
- 個人頁：信用分數 + 完成次數 + 近期評價摘要
- 低於門檻不可發起狗狗交友邀約

---

## 金流：訂閱制（MVP）

**原則：** 第一版不抽單場佣金、不做 C2C 託管。營收來自**訂閱**。配對成功後雙方自行溝通與見面。

### 誰付錢
| 意圖 | 錢怎麼走 |
|------|----------|
| 瀏覽附近主人／狗檔案 | 免費（可限次數或模糊結果） |
| 發起／接受邀約、解鎖聊天與集合點 | 需有效訂閱 |
| 見面現場 | 平台不經手；禁止引導私下當成「平台託管」 |

同一帳號只有「訂閱中／未訂閱」。沒有 payer／payee 場次帳本、沒有幫忙者錢包、沒有銀行提領。

### 訂閱內容（建議）
- **免費：** 建立狗檔案、看附近列表（距離／公園模糊）、看規則卡
- **訂閱後：** 發起邀約、接受邀約、解鎖精確集合點、簡易聊天、互評
- 雙方都需訂閱才能聊天（避免一方付費、另一方白嫖溝通）
- 未訂閱可收到「有人想約你」通知，點進去才引導訂閱

### 付款
- MVP 只收 **LINE Pay**（訂閱週期：月繳）。不做信用卡／Apple Pay／ATM／超商代碼（v2 再加）。
- 付不了 LINE Pay → 無法開通邀約／聊天。
- 週期自動續訂；取消後用到該期結束。
- 特店需公司／獨資登記；清算進平台公司銀行戶。

### 不做（刻意砍掉）
- 每場代遛／一起遛的授權 → 請款 → 託管 → 90% 撥出
- 錢包、提領 KYC、最低提領額
- 取消／放鳥的分帳規則（放鳥只影響信用，不涉及退款拆帳）

## MVP 範圍

### 做
- 探索：附近列表／簡易地圖（附近主人，模糊到商圈／公園）
- 狗檔案＋規則卡（預設一包 + 主人勾選）
- 邀約：提出見面（公園＋時段＋15／30 分建議）→ 接受 → 解鎖集合點＋簡易聊天
- **之後交給主人自己處理**
- 訂閱：LINE Pay 月繳；訂閱後才能邀約／聊天
- 可選互評＋現場照＋信用分數
- 基礎驗證：手機簡訊；檢舉／封鎖

### 不做（第一版）
- 一起遛狗（行程卡／路段／步調／進行中狀態）
- 幫忙遛狗（代遛、接送點託管、幫忙者角色）
- 場次金流、錢包、銀行提領
- GPS 軌跡、強制結束回報

```
  → 狗檔案＋規則
  → 邀約（需訂閱）
  → 聊天＋集合點（需雙方同意）
  → 自己見面

我的邀約（待回覆／已接受／歷史）
個人／狗檔案／信用／訂閱
```

## 冷啟動
先做滿單一行政區／單一熱門公園，密度優先。狗狗交友吃「同一座公園的重疊」，公園選對比功能多更重要。
