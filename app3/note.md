# 寵物交友 MVP

## 定位
本地狗主人找附近狗主人，讓兩隻狗互相認識。

第一版只做**主人 ↔ 主人**。平台負責「找得到對的鄰居」；**訂閱後雙方自己約、自己處理**，不做代遛、不做一起遛行程、不做場次託管金流。

## 角色
單一角色：**狗主人**。上架狗檔案、瀏覽附近主人（可用時段勾選篩選）、發出／接受 Connect、聊天。特定公園可由主揪辦短期聚會。

> v2 再考慮：幫忙遛狗（代遛）。一起遛狗（行程卡）不做。

## 第一版試用

試用版服務範圍、創始名額與未訂閱權限如下。後續章節與本節衝突時，**以本節為準**。

### 服務範圍（定位縣市＋即時行政區 API）

試用只服務這四個直轄市：**高雄市、台南市、新北市、台北市**。行政區**不寫死在產品裡**，一律即時 API 抓；而且**只抓用戶目前所在的那一個縣市**，不預載另外三市、不預載全台。

**怎麼抓**
1. 裝置定位 → 反向地理編碼得到**目前所在縣市**（必要時一併得到目前所在區，僅作預選，不當寫死清單）。
2. 縣市不在試用四市 → 提示尚未開放，不載行政區、不開探索清單。
3. 縣市在試用四市 → 用該縣市代碼打即時行政區 API，**只回傳該縣市的區**。這份清單才拿來選區、篩選、「該區」皇冠。
4. 定位拒絕／失敗 → 無法知道所在縣市，不給縣市下拉當備案（以免一次載多市、或寫死名單）。引導開定位後重試。
5. 當次 session 可短時快取「這一市的區」，換縣市或重新定位就重抓。不當成長期寫死資料。

- 檔案上的行政區從 API 回傳的該市清單勾選；公園／出沒處由用戶自行輸入，掛在已選的區底下。
- 探索清單、filter、皇冠都只看**目前所在縣市**（全域假資料除外，見下）。不提供切到其他縣市瀏覽。
- 定位只用來判定縣市並拉該市行政區；**不是**會面過程的 GPS 軌跡。

### 創始白名單（限額 100 人，不驗證碼）

試用版**不發簡訊驗證碼**。前 **100** 個建立帳號的人寫進**創始白名單**，視為永久免費訂閱（不必 LINE Pay，不會到期）。

**免費註冊必須同時建立狗檔案。** 只填手機號、沒有狗檔案，不算完成註冊、不佔白名單。避免有人註冊後空帳號。

**身份（白名單要對得上的東西）**
- 帳號鍵用可帶到下一版的身份，**不用 device id**（換機／重裝會丟）。
- 試用：用戶填**手機號**當 `login_key`，不驗證簡訊。同一支號碼下次登入仍是同一人。
- 正式建議再綁 Sign in with Apple／Google 到同一列白名單，換機仍認得出。
- 白名單存在**雲端**（`founder_whitelist`）。不要只寫在手機裡，也不要把可竄改的名單當唯一依據。下次升級可把當時的 100 筆打成 App 內 snapshot 當備援，仍以伺服器為準。

**試用版（現在）**
- 前 100 人：填手機號 **＋ 建立狗檔案** 才完整使用（詳情、Connect、聊天）。
- 名額以雲端寫入白名單的時間排序；滿 100 即關。不可補發、不可轉讓。
- 第 101 人起：可看清單；詳情／Connect／聚會報名要等訂閱（試用期間若尚未開 LINE Pay，就先停在清單）。

**正式版（下次版本升級）**
- App 打開全站訂閱牆。
- **白名單內 = 已事先訂閱**，不必再付費，權限與付費訂閱相同。
- **不在白名單** → LINE Pay 月繳後才能看詳情／Connect。
- 升級時不清帳號、不換 `login_key`，那 100 人打開新版仍是已訂閱。

### 未訂閱能做什麼

| | 白名單 100 人（已事先訂閱） | 第 101 人起、尚未訂閱 | 已訂閱（含白名單） |
|--|---------------------------|----------------------|------------------|
| 看探索清單（全部主人＋時段勾選＋公園聚會預覽） | 可 | **可（僅此）** | 可 |
| 點進主人詳情 | 可 | 不可；點清單卡改引導訂閱 | 可 |
| 建立／編輯狗檔案（個人資料） | 可（註冊當下必須完成） | **不可** | 可 |
| 發起／接受 Connect、聊天、集合點、互評、聚會報名 | 可 | **不可** | 可 |

- 未訂閱（且不在白名單）**只能看清單**。要看詳情、Connect、報名聚會，都必須先訂閱。
- 沒有檔案的人不會出現在清單上，別人也不能對他發 Connect。免費註冊當下就必須有檔案。
- 不再做「未訂閱可建檔、可看詳情、個人頁先看邀請再引導付費」；第 101 人起，下一步一律先訂閱。

## 產品原則（MVP）

1. **找得到對的人**比功能多更重要：探索一次列出全部主人，可用時段**勾選**篩選。未訂閱也能掃清單；詳情與 Connect 要訂閱（創始 100 人除外，見上）。
2. **訂閱後自己處理**：平台不追蹤進行中路段、不託管每場付款、不強制結束回報才能繼續用。聚會報名費也是**當場繳給主揪**。
3. **安全用 Connect 成功提醒＋解鎖聊天**：精確集合點與聊天在雙方都接受 Connect 後才開；成功當下顯示一段見面提醒（不是檔案上的規則卡）。對話上限 **20 句**。
4. **不是動態牆**：沒有公開動態、沒有群組遛。公園聚會是主揪場次，不是動態牆。
5. **清單只給掃一眼的資訊**：照片、時段、地點、出去次數；個性與 Connect 按鈕只在點進主人詳情後才出現。
6. **清單排序看實際出門，其次看檔案有沒有填滿**：先依**出去次數**由高到低；次數相同再依**個人資料豐富程度**由高到低。

## 建立檔案（系統選項 vs 用戶輸入）

建立狗檔案時，欄位來源分開。**免費註冊必須同時完成狗檔案**（創始 100 人的永久免費訂閱算有效）。

| 欄位 | 怎麼填 | 上限 |
|------|--------|------|
| **縣市** | 由定位即時判定，不手選、不寫死 | 僅用戶目前所在縣市 |
| **行政區** | 即時 API 只抓該縣市的區，用戶勾選 | 一個主要行政區 |
| **個性** | 系統提供選項，用戶勾選 | 友善／怕生／活力／慢熱 |
| **時段** | 系統提供選項，用戶勾選 | 清單最多顯示 **3** 個 |
| **地點** | 用戶自行輸入（公園名、常見出沒處等），掛在已選行政區下 | 清單最多顯示 **3** 個 |
| **簡短介紹** | 用戶自行輸入 | **50 字內** |

### 個性（系統選項）
友善／怕生／活力／慢熱

不做：高齡、幼犬。清單上看不到個性；點進主人詳情才顯示。

### 時段（系統選項）
兩軸勾選，組合成出沒時段：

- **日型：** 平日、假日
- **時段：**
  - 早上（11 點前）
  - 中午（11–14）
  - 下午（14–17）
  - 傍晚（17–19）
  - 晚上（19 以後）

例：平日早上、假日傍晚。清單最多顯示 3 個時段；超過則建立時限制或只露出前 3 個。

### 地點
用戶自行輸入建立地點（例：中央公園、凹子底森林公園）。不把行政區名稱當成清單上的公園名；行政區來自所在縣市的即時 API，公園名是用戶填的地點。清單最多顯示 3 個地點。精確集合點仍等雙方 Connect 成功後才給，不露住家。

## 頁面流程

未訂閱可看清單；**主人詳情、Connect／聊天、聚會報名都要有效訂閱**（創始 100 人已是永久免費訂閱）。免費註冊＝手機號＋狗檔案同時完成。對方也必須接受才能開始聊。

```
探索（清單免費，無需訂閱）
  ├─ 公園聚會（特定公園、需主揪、10 人內、日期一週內、報名費當場繳）
  ├─ 時段勾選篩選
  ├─ 鄰汪夥伴（2 筆全域假資料，所有人看得到）
  └─ 全部主人（目前所在縣市；可再依行政區縮小）
        → 排序：出去次數高→低；相同則資料豐富程度高→低
        → 清單卡：照片、時段（最多 3）、地點（最多 3）、出去次數
              → 點進去（需訂閱）：主人詳情（含個性、簡短介紹）＋ Connect 按鈕
                    → Connect 成功：顯示見面提醒
                    → 對話窗（需 Connect：對方也接受才能開始聊天；最多 20 句）
                          → 雙方自己約細節、自己見面

個人頁（免費註冊必須同時建立狗檔案）
  └─ Connect 邀請（待回覆／已送出／已接受／歷史）
```

未訂閱點清單卡、點任何 Connect 入口或聚會報名 → 訂閱頁（白名單仍有空位則引導去「我的」填手機號＋狗檔案佔名額，不必驗證碼；已滿則走 LINE Pay 月繳）。

### 探索首頁（第 2 頁）
- **不做**「依地點／依時間／主人清單」分頁。一次列出全部主人。
- **時段篩選：** 系統時段用**勾選**（可複選）。沒勾＝全部；有勾＝時段有重疊才顯示。
- 可用該市行政區縮小範圍。不可切到其他縣市。
- 頁面上方加**公園聚會**（見下）。
- 清單頂部固定兩筆**全域假資料**（鄰汪夥伴），每位登入用戶都看得到。
- 所有探索清單同一套**排序**（見下方；假資料置頂、不參與該區皇冠）。

### 全域假資料＋新手教學

兩筆 global 檔案（團團／可可），不綁縣市，所有人看得到。

登入並完成狗檔案後，進入**新手教學 tour**：
1. 要求用戶 Connect **團團** → 團團**一定會回**（立刻接受）並主動傳訊息。
2. 再請用戶**嘗試 Connect 可可** → 可可也會回並主動傳訊息。
3. 介紹公園聚會後結束教學。

兩筆假資料都會在 Connect 成功後主動傳訊息。可略過教學，但假資料仍留在清單上。

### 公園聚會

探索頁可看到**特定公園**開放辦聚會：

- **需要主揪**（沒有主揪不成局）
- **人數限定 10 人內**
- **日期一週內**
- **報名費當場繳給主揪**，平台不經手、不做金流託管

未訂閱可預覽聚會卡；報名需有效訂閱。額滿不可再報。

### 清單卡（長條形）

所有探索清單同一套橫列卡，**不是**大方塊／網格。

**清單上只顯示**
- **照片：** 大頭貼。**必須是狗主人與狗的合照**（兩者都要入鏡）；只放狗、只放主人、或無法辨識者不通過、不上清單
- **時段：** 最多 **3** 個（系統選項）
- **地點：** 最多 **3** 個
- **出去次數**
- 名字（狗名為主；可附主人暱稱）仍可放在卡上當識別，但**不顯示個性**

**清單上不顯示**
- 個性（點進去才看）
- Connect 次數（點進去才看）
- Connect 按鈕（點進去才有）
- 簡短介紹（點進去才看）

整列可點進主人詳情（未訂閱則改引導訂閱，不開詳情）。

### 清單排序

附近主人（不含置頂假資料）同一套排序：

1. **出去次數**由高到低（雙方都按「已見面」才算的那個數）。
2. 出去次數相同 → **個人資料豐富程度**由高到低。
3. 豐富程度仍相同 → 先註冊者在前。

**個人資料豐富程度**（用來比序，不在清單上顯示分數）

每填一項加分；沒填不加。分數只用於排序。

| 項目 | 分數 |
|------|------|
| 合照通過審核（主人＋狗都入鏡） | 3 |
| 品種／混種 | 1 |
| 體型 | 1 |
| 年齡區間 | 1 |
| 個性：每勾 1 個標籤 | 1（最多 4） |
| 時段：每勾 1 組 | 1（最多以清單露出的 3 組計） |
| 地點：每建立 1 個地點 | 1（最多 3） |
| 簡短介紹 | 1 |
| 與其他狗（已選一項） | 1 |
| 行政區已選（來自所在縣市 API） | 1 |

沒有檔案或合照未過審 → 不上清單，不參與排序。

**特效框：新用戶**
- 剛註冊、尚未完成第一次「雙方互按已見面」的主人，清單卡外框有**新用戶特效框**（例如柔光描邊／閃爍，與一般卡明顯不同）
- 第一次出去次數 +1 後拿掉特效框，之後不再顯示

**皇冠：該區出去次數前三名**
- 以**目前所在行政區**的出去次數排名（同分時 Connect 次數高者在前；再同分則先註冊者在前）
- 該區第 1／2／3 名，清單卡上依序顯示**金／銀／銅皇冠**
- 只在「該區」清單顯示該區排名；切到同市別區時不沿用他區皇冠。探索本身不跨縣市。
- 全域假資料不佔該區皇冠。
- 新用戶特效框與皇冠可並存
- 皇冠是該區徽章，**不改**上面的清單排序規則

### 主人詳情（從清單點進去）

需有效訂閱才看得到（創始 100 人已具備）。未訂閱點清單卡 → 訂閱頁。

訂閱後可看：
- 照片（主人＋狗合照）
- **簡短介紹**（50 字內）
- 狗的類型（品種／混種、體型）
- **個性**（系統選項勾選結果；清單上看不到）
- 時段（系統選項）
- 地點（模糊到區域，不露住家）
- 兩個數值：**出去次數**、**Connect 次數**
- **Connect 按鈕**

詳情頁**不再放規則卡**。見面提醒只在 Connect 成功時顯示一次。

精確集合點要等雙方 Connect 成功後才給。

### Connect 與對話窗
- 從主人詳情按 **Connect 按鈕** 發出邀請；對方在**個人頁**看到邀請並接受後，才能開始聊天。單方送出不算開始。
- 雙方都必須有效訂閱（創始永久免費也算）才能發起或接受。
- 聊天最多 **20 句**（雙方合計）。滿了就不能再送，之後改由雙方自行約。
- Connect 成功後解鎖：簡易聊天＋精確集合點（若有填）。
- **每次 Connect 成功時**顯示見面提醒（一段文字，見下）。檔案上不再勾規則卡。
- 雙方自己約細節、自己見面、自己善後。

建議預設文案（非強制行程）：**公園平行走 15 分鐘**（兩狗牽繩、保持距離）→ 雙方覺得 OK 再靠近。第一次不當成「放繩對玩」。

平台**不**做：進行中狀態機、GPS 軌跡、結束必傳照片才解鎖、每場 LINE Pay。

### 見面提醒（Connect 成功時才顯示）

取代規則卡。不當場監控；違規靠檢舉。

見面提醒：雙方主人請全程在場。第一次請約公共公園，不要約私人庭院或室內。全程牽繩，直到雙方口頭同意才靠近。體型差大時預設平行走、不互相撲。若任一方的狗出現壓力訊號（躲、吠、低吼、身體僵硬），立刻拉開並結束當次。合照需當下口頭同意；夜間不要用閃光燈直射眼睛。現場怎麼走由你們自己決定。

### 個人頁：Connect 邀請

Connect 邀請集中在**個人頁**看，不另外做獨立 inbox 當主入口。

**免費註冊＝手機號＋狗檔案同時完成。** 沒有狗檔案就不算註冊成功，不能只佔白名單空號。

個人頁可見：
- **待回覆：** 別人對我發出的 Connect（接受／拒絕）
- **已送出：** 我對別人發出、對方尚未回覆
- **已接受／歷史：** 成功 Connect 與過去紀錄
- 自己的狗檔案、出去次數、Connect 次數、訂閱狀態（含是否為創始永久免費）

未訂閱進入個人頁 → 直接引導訂閱。不做「先看邀請再付費才接受」。

## 核心流程 — 狗狗交友

讓主人依出沒時段找到附近有狗的主人，約戶外見面。重點是配對與溝通，不是行程管理。特定公園可另辦主揪聚會。

### 探索（搜尋附近主人）

| 篩選 | MVP |
|------|-----|
| **縣市** | 定位即時判定；僅用戶目前所在縣市。試用四市以外不開 |
| **行政區** | 不寫死；即時 API **只抓該縣市的區**。篩選與「該區」皇冠用這份清單 |
| **地點** | 用戶建立的地點（掛在該市行政區下）。不露住家。清單最多顯示 3 個地點 |
| **時間** | 探索頁用**勾選**篩選（平日／假日 × 早上／中午／下午／傍晚／晚上）。不做依時間分頁 |
| **主人清單** | 一次顯示全部（外加 2 筆全域假資料置頂）。可用該市行政區、時段勾選。長條形橫列：照片、時段（最多 3）、地點（最多 3）、出去次數；**排序：出去次數 → 資料豐富程度**；新用戶特效框；該區出去次數前三名依序金／銀／銅皇冠。個性與 Connect 按鈕在點進去後才出現 |
| **公園聚會** | 特定公園、需主揪、10 人內、日期一週內、報名費當場繳 |
| **體型** | 小型／中型／大型；體型差兩級要警示（大狗嚇到小狗） |
| **個性** | 系統選項：友善／怕生／活力／慢熱。建立時勾選；**僅詳情頁顯示**，清單不顯示 |
| **能否與其他狗互動** | 可一起玩／需慢熱牽繩平行走 |
| **簡短介紹** | 50 字內；僅詳情頁 |
| **信用／門檻** | 清單看出去次數；詳情另看 Connect 次數。發起 Connect 需有效訂閱 |

## 主人公開數值（兩個）

| 數值 | 清單 | 詳情／個人頁 | 怎麼算 |
|------|------|-------------|--------|
| **出去次數** | 顯示 | 顯示 | 和其他人實際出門見面的次數。**雙方都按「已見面」才 +1**；單方按不算。清單**第一排序鍵**。 |
| **Connect 次數** | 不顯示 | 顯示 | 成功 Connect 的次數（對方也接受才算；單方送出不算）。 |

- 出去次數與 Connect 次數分開：Connect 成功但沒出門，只加 Connect、不加出去。
- 低於門檻不可發起 Connect（門檻用出去次數／檢舉紀錄，細節 v1 先簡單切）。
- 出去次數相同時，清單改比**個人資料豐富程度**（見清單排序）。

## 狗檔案（MVP 欄位）
- **縣市**（定位即時判定，僅所在縣市）＋**行政區**（即時 API 只抓該市的區，不寫死）
- 名字、**大頭貼（必須為狗主人與狗的合照，兩者都要入鏡）**、品種／混種、體型、年齡區間
- **簡短介紹：** 50 字內
- **個性：** 系統選項勾選（友善／怕生／活力／慢熱）；僅詳情頁顯示
- **時段：** 系統選項勾選（平日／假日 × 早上 11 點前／中午 11–14／下午 14–17／傍晚 17–19／晚上 19 以後）；清單最多 3 個
- **地點：** 用戶自行輸入；清單最多 3 個；精確點 Connect 後再給
- **與其他狗：** 可一起玩／需慢熱平行走
- 可否合照（預設可，主人可關）
- **出去次數**（清單＋詳情）、**Connect 次數**（僅詳情／個人頁）

不做：規則卡勾選、不適合交友、高齡／幼犬標籤。

免費註冊必須同時完成狗檔案。欄位填越完整，清單在出去次數相同時排越前面。

## 見面確認與信用

完成見面後**可選**上傳照片＋互評（不擋繼續使用）。

**出去次數（硬規則）**
- 必須**雙方都按「已見面」**才 +1。單方按、只互評、只上傳照片都不算出去次數。

**加分／展示（可選）**
- 準時、完成見面（雙方已互按）
- 上傳現場照（簡單審核：戶外、有狗、無違規）
- 對方給正面評價

**扣分／凍結**
- 放鳥、遲到嚴重、違規解繩／強行靠近對方的狗、未經同意拍照／傳播
- 被檢舉且成立 → 扣分；嚴重則暫停 Connect 權

**展示**
- 清單：照片、時段（最多 3）、地點（最多 3）、出去次數；新用戶特效框；該區出去次數前三名金／銀／銅皇冠。排序：出去次數 → 資料豐富程度
- 詳情／個人頁：出去次數 + Connect 次數 + 個性 + 簡短介紹 + 近期評價摘要（若有）
- 低於門檻不可發起 Connect

## 金流：訂閱制（MVP）

**原則：** 第一版不抽單場佣金、不做 C2C 託管。營收來自**訂閱**。Connect 成功後雙方自行溝通與見面。聚會報名費當場繳給主揪。

同一帳號狀態：**創始永久免費**／**訂閱中**／**未訂閱**。前兩者都算有效訂閱。沒有 payer／payee 場次帳本、沒有幫忙者錢包、沒有銀行提領。

### 誰付錢
| 意圖 | 錢怎麼走 |
|------|----------|
| 看探索清單（全部主人、時段勾選、聚會預覽；照片、最多 3 時段、最多 3 地點、出去次數） | 免費 |
| 建立／編輯狗檔案（個人資料） | 免費註冊當下必須完成；第 101 人起需有效訂閱 |
| 看主人詳情（含個性、介紹、Connect 次數）、發起／接受 Connect、解鎖聊天（最多 20 句）與集合點、互評、聚會報名 | 需有效訂閱 |
| 見面現場／聚會報名費 | 平台不經手；禁止引導私下當成「平台託管」 |

### 訂閱內容

- **免費（未訂閱）：** 只看清單。不可看詳情、不可 Connect、不可報名聚會。
- **有效訂閱後：** 看主人詳情、發起／接受 Connect、解鎖精確集合點、對話窗（最多 20 句）、互評、聚會報名。
- **創始 100 人：** 試用期寫入白名單的前 100 個 `login_key`（手機號＋狗檔案，不驗證碼）。下次升級後白名單視為已事先訂閱，不必再付。權限與付費訂閱相同。
- 雙方都需有效訂閱才能聊天（避免一方付費、另一方白嫖溝通）。
- 第 101 人起沒有「先看邀請再付費」；要 Connect 一律先訂閱。

### 付款
- MVP 只收 **LINE Pay**（訂閱週期：月繳）。不做信用卡／Apple Pay／ATM／超商代碼（v2 再加）。
- 白名單內（創始 100）不必走 LINE Pay。
- 付不了 LINE Pay（且不在白名單）→ 無法開通 Connect／聊天／聚會報名。
- 週期自動續訂；取消後用到該期結束。創始永久免費沒有取消到期這件事。
- 特店需公司／獨資登記；清算進平台公司銀行戶。

### 不做（刻意砍掉）
- 每場代遛／一起遛的授權 → 請款 → 託管 → 90% 撥出
- 錢包、提領 KYC、最低提領額
- 取消／放鳥的分帳規則（放鳥只影響信用，不涉及退款拆帳）
- 聚會報名費走平台金流（改當場繳給主揪）

## MVP 範圍

### 做
- 服務範圍：試用四市（高雄、台南、新北、台北）；縣市由定位判定；行政區**不寫死**，即時 API **只抓用戶所在縣市**
- 創始白名單 100 人：填手機號**＋同時建立狗檔案**，**不驗證碼**；下次升級後白名單視為已事先訂閱。第 101 人起未訂閱只能看清單
- 探索：只看目前所在縣市；一次列出全部主人；時段用勾選篩選。不做地點／時間／主人清單分頁
- 2 筆全域假資料（團團、可可）所有人看得到；登入後新手教學要求 Connect；團團一定會回；可可也可試 Connect；兩者都主動傳訊息
- 公園聚會：特定公園、需主揪、10 人內、日期一週內、報名費當場繳
- 清單為長條形橫列：**照片、時段（最多 3）、地點（最多 3）、出去次數**；排序為**出去次數 → 資料豐富程度**；新用戶特效框；該區出去次數前三名依序金／銀／銅皇冠。個性不在清單上
- 建立檔案：免費註冊當下必須完成；縣市由定位判定；行政區由該市即時 API 勾選；個性與時段為系統選項；地點由用戶輸入；簡短介紹 50 字內
- 從清單點進主人詳情（需訂閱）：類型、**個性**、介紹、時段與地點、兩個數值、**Connect 按鈕**；大頭貼限合照
- Connect：從詳情頁按鈕發出；邀請在**個人頁**看；需對方接受才能開始聊天；對話最多 20 句；**成功時顯示見面提醒**
- 兩個公開數值：出去次數（雙方互按才 +1；清單顯示、第一排序鍵）、Connect 次數（雙方接受才 +1；僅詳情／個人頁）
- **之後交給主人自己處理**
- 訂閱：LINE Pay 月繳；訂閱後才能看詳情／Connect／聊天／聚會報名
- 可選互評＋現場照
- 帳號鍵：手機號（不驗證碼）；檢舉／封鎖
- 創始白名單存在雲端；正式版以白名單跳過付費牆

### 不做（第一版）
- 一起遛狗（行程卡／路段／步調／進行中狀態）
- 幫忙遛狗（代遛、接送點託管、幫忙者角色）
- 場次金流、錢包、銀行提領（含聚會報名費）
- 會面過程 GPS 軌跡、強制結束回報（定位只用於判定所在縣市）
- 超過 20 句的長聊天／群組聊
- 清單上顯示個性或 Connect 按鈕
- 用戶自訂時段文案（時段只准系統選項）
- 寫死行政區名單、預載全台或四縣市全部區
- 讓用戶手選／切換到非目前所在的縣市
- 定位失敗時改用寫死縣市下拉當備案
- 未訂閱看詳情或 Connect
- 只填手機號、不建狗檔案就完成免費註冊
- 規則卡勾選（改 Connect 成功提醒）
- 個性「高齡」「幼犬」；「不適合交友」
- 探索的地點／時間／主人清單分頁
- 創始名額超過 100、名額轉讓／補發
- 用簡訊驗證碼當創始資格（改白名單）
- 用 device id 當白名單（換機會丟）
- 只把白名單寫在客戶端、不進雲端

## 資訊架構
```
探索（清單免費；僅目前所在縣市）
  ├─ 公園聚會（特定公園／主揪／10 人內／一週內／現場繳費）
  ├─ 時段勾選篩選
  ├─ 鄰汪夥伴（2 筆全域假資料）
  └─ 全部主人（該市行政區可縮小）
        → 排序：出去次數 → 資料豐富程度
        → 長條清單（照片／時段最多 3／地點最多 3／出去次數；新用戶特效框；該區前三皇冠）
              → 主人詳情（需訂閱：介紹／個性／類型／時段／地點／兩個數值）＋ Connect 按鈕
                    → Connect 成功 → 見面提醒
                    → 對話窗（最多 20 句）＋集合點
                          → 自己見面
                                → 雙方互按「已見面」→ 出去次數 +1

個人頁（免費註冊＝手機號＋狗檔案同時完成）
  ├─ Connect 邀請（待回覆／已送出／已接受／歷史）
  ├─ 狗檔案（縣市＝定位；行政區＝該市即時 API；個性／時段系統選；地點自填；介紹 50 字）
  ├─ 出去次數／Connect 次數
  └─ 訂閱（白名單已事先訂閱／月繳中／未訂閱）
```

## 冷啟動
試用四市可進（高雄、台南、新北、台北），但每人當下只看到**自己所在縣市**（外加 2 筆全域假資料）。行政區不寫死，定位後即時 API 只抓該市。密度靠創始白名單 100 人先把檔案填實（填手機號＋狗檔案，不驗證碼）。兩筆假資料負責第一個 Connect 與第一句訊息，降低空城感。地點由用戶填、掛在該市行政區下；時段用系統選項填實。特定公園由主揪開一週內、10 人內的現場繳費聚會。清單把出去次數高、檔案填得完整的人排前面，鼓勵先出門、先把資料補齊。下次升級打開訂閱牆時，這 100 個 `login_key` 已在白名單，不必再付費。
