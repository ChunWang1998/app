# 寵物交友 MVP

## 定位
本地狗主人找附近狗主人，讓兩隻狗互相認識。

第一版只做**主人 ↔ 主人**。平台負責「找得到對的鄰居」；**訂閱後雙方自己約、自己處理**，不做代遛、不做一起遛行程、不做場次託管金流。

## 角色
單一角色：**狗主人**。上架狗檔案、瀏覽附近主人、發出／接受 Connect、聊天。可在個人頁創辦**汪汪聚會**。

> v2 再考慮：幫忙遛狗（代遛）。一起遛狗（行程卡）不做。

## 第一版試用

試用版服務範圍、創始名額與未訂閱權限如下。後續章節與本節衝突時，**以本節為準**。

### 服務範圍（定位縣市＋即時行政區 API）

試用只服務這四個直轄市：**高雄市、台南市、新北市、台北市**。行政區**不寫死在產品裡**，一律即時 API 抓；而且**只抓用戶目前所在的那一個縣市**，不預載另外三市、不預載全台。

**怎麼抓**
1. 裝置定位 → 反向地理編碼得到**目前所在縣市**（必要時一併得到目前所在區，僅作預選，不當寫死清單）。
2. 縣市不在試用四市 → 提示尚未開放，不載行政區、不開探索清單。
3. 縣市在試用四市 → 用該縣市代碼打即時行政區 API，**只回傳該縣市的區**。這份清單才拿來選區、篩選、「該區」皇冠。
4. 定位拒絕／失敗 → 無法知道所在縣市，不給縣市下拉當備案（以免一次載多市、或寫死名單）。引導開定位後重試。
5. 當次 session 可短時快取「這一市的區」，換縣市或重新定位就重抓。不當成長期寫死資料。

- 檔案上的行政區從 API 回傳的該市清單勾選；公園／出沒處由用戶自行輸入，掛在已選的區底下。
- 探索清單、filter、皇冠都只看**目前所在縣市**（範例汪汪除外，見下）。不提供切到其他縣市瀏覽。
- 汪汪聚會列表也以**一個市**為單位，只看目前所在縣市。
- 定位只用來判定縣市並拉該市行政區；**不是**會面過程的 GPS 軌跡。

### 創始白名單（限額 100 人，不驗證碼）

試用版**不發簡訊驗證碼**。前 **100** 個建立帳號的人寫進**創始白名單**，視為永久免費訂閱（不必付費、不會到期）。

**免費註冊必須同時建立狗檔案。** 只填手機號、沒有狗檔案，不算完成註冊、不佔白名單。避免有人註冊後空帳號。

**身份（白名單要對得上的東西）**
- 帳號鍵用可帶到下一版的身份，**不用 device id**（換機／重裝會丟）。
- 試用：用戶填**手機號**當 `login_key`，不驗證簡訊。同一支號碼下次登入仍是同一人。
- 正式建議再綁 Sign in with Apple／Google 到同一列白名單，換機仍認得出。
- 白名單存在**雲端**（`founder_whitelist`）。不要只寫在手機裡，也不要把可竄改的名單當唯一依據。下次升級可把當時的 100 筆打成 App 內 snapshot 當備援，仍以伺服器為準。

**試用版（v1，現在）**
- 只服務創始 **100** 人。填手機號 **＋ 建立狗檔案** 才寫入白名單（同一筆雲端交易）。沒有狗檔案不佔名額。
- 名額以雲端寫入白名單的時間排序；不可補發、不可轉讓。v1 **不預期超過 100 人**，也不收款。
- 同一支號碼換機輸入後從雲端還原，不必重填。
- 縣市由定位判定，不能在 App 內切到其他縣市。

**正式版（v2）**
- **Apple 內購**月繳後才能主動 Connect／報名／創辦聚會（不要在 iOS App 內用 LINE Pay 解鎖數位功能）。
- **v1 白名單內 = 已事先訂閱**，不必再付費，權限與付費訂閱相同。
- 未訂閱可以：建立／編輯檔案、看附近的人（含詳情）、看聚會、**看得到** Connect 邀請。
- 未訂閱不可以：主動 Connect、接受邀請並聊天、報名／創辦聚會。
- 已付費**可以對未訂閱發 Connect**；對方要訂閱後才能接受／聊天。
- 升級時不清帳號、不換 `login_key`。可把當時的 100 筆打成 App 內 snapshot 當備援，仍以伺服器為準。

### 未訂閱能做什麼

v1 實際上只有白名單用戶。下表是 **v2** 權限（已付費可對未訂閱發 Connect）。

| | 白名單（已事先訂閱） | 尚未訂閱（v2） | 已訂閱（含白名單） |
|--|--|--|--|
| 看探索清單與聚會頁預覽 | 可 | 可 | 可 |
| 點進主人詳情 | 可 | 可 | 可 |
| 建立／編輯狗檔案 | 可（註冊當下必須完成） | 可 | 可 |
| 看 Connect 邀請 | 可 | 可（不能接受） | 可 |
| 發起 Connect、接受並聊天、創辦／報名汪汪聚會 | 可 | **不可** | 可 |

- 沒有檔案的人不會出現在清單上，別人也不能對他發 Connect。v1 免費註冊當下就必須有檔案。

## 雲端與上架（v1）

試用版可以單機跑（AsyncStorage）。**要給兩個真人互相 Connect／聊天、或上 App Store，必須接 Supabase。** 設好 `EXPO_PUBLIC_SUPABASE_URL` 與 `EXPO_PUBLIC_SUPABASE_ANON_KEY` 後，App 改走雲端：

| 資料 | 雲端表／服務 |
|------|----------------|
| 帳號、創始白名單 | `accounts`、`founder_whitelist`（RPC `register_founder`、`login_with_phone`） |
| 狗檔案、出去／Connect／大隊長數值 | `profiles`（次數由伺服器加，客戶端不能自改） |
| 合照 | Storage bucket `avatars` |
| Connect／聊天／已見面 | `connects`、`messages`、`meet_confirms` |
| 汪汪聚會、報名、按讚 | `gatherings`、`gathering_joins`、`gathering_likes` |
| 檢舉／封鎖 | `reports`、`blocks` |

**上架前必做（Dashboard）**
1. 執行 `app3/supabase/schema.sql`（含 RLS 與 RPC）。
2. 把同一個 env 寫進 **EAS Secrets** 再打 production build（本機 `.env` 不會進 App Store 包）。
3. 拿掉示範按鈕（已從正式 UI 移除：模擬對方接受、模擬已見面、LINE Pay 示範開通、種子假 LINE 群）。

**這一版金流**
- **不收錢。** 創始 100 人免費。v1 不預期超過 100 人。不在 iOS 用 LINE Pay 解鎖功能（Apple 3.1.1）。
- 下版付費改 **Apple 內購** 月繳，不在 App 內用 LINE Pay 開通 Connect／聊天。

**審核已做**
- 個人頁可 **刪除帳號**（雲端列標記刪除並清檔案／對話；白名單名額不退）。
- 主人詳情可 **檢舉**、**封鎖**（封鎖後互不出現、Connect 解除）。
- 範例汪汪（團團、可可）仍在，標成範例，給教學用。與真人之間的 Connect／聊天走雲端。

**尚未做（v2）**
- Sign in with Apple（欄位 `accounts.apple_sub` 已留）。試用仍用手機號當 `login_key`、不驗證碼。
- 真推播（APNs）；現在聊天靠輪詢。
- Apple 內購；未訂閱可建檔／看詳情／看邀請的權限牆。

**身份（試用）**
RPC 以 `login_key`（手機號）當操作者。表格不給 anon 直寫；公開讀取僅限已完成合照的檔案與聚會。換機輸入同一支手機號可還原雲端帳號。

## 產品原則（MVP）

1. **找得到對的人**比功能多更重要：探索看**鄰汪夥伴**，可用時段**勾選**篩選。未訂閱也能掃清單；詳情與 Connect 要訂閱（創始 100 人除外，見上）。
2. **訂閱後自己處理**：平台不追蹤進行中路段、不託管每場付款、不強制結束回報才能繼續用。汪汪聚會收費由主辦者標示，平台不經手。
3. **安全用 Connect 成功提醒＋解鎖聊天**：精確集合點與聊天在雙方都接受 Connect 後才開；成功當下顯示一段見面提醒（不是檔案上的規則卡）。對話上限 **20 句**。送出按鈕用類似 LINE 的**小飛機 icon**，不用「送」字。
4. **不是動態牆**：沒有公開動態、沒有群組遛。汪汪聚會是主辦場次，不是動態牆；報名後改走 **LINE 群組**。
5. **清單只給掃一眼的資訊**：照片、時段、地點、出去次數；個性與 Connect 按鈕只在點進主人詳情後才出現。
6. **清單排序看實際出門，其次看檔案有沒有填滿**：先依**出去次數**由高到低；次數相同再依**個人資料豐富程度**由高到低。
7. **汪汪聚會按市、按大隊長分數**：活動列表以**一個市**為單位；主辦人的**汪汪大隊長分數**越高，顯示越上面。

## 建立檔案（系統選項 vs 用戶輸入）

建立狗檔案時，欄位來源分開。**免費註冊必須同時完成狗檔案**（創始 100 人的永久免費訂閱算有效）。

| 欄位 | 怎麼填 | 上限 |
|------|--------|------|
| **縣市** | 由定位即時判定，不手選、不寫死 | 僅用戶目前所在縣市 |
| **行政區** | 即時 API 只抓該縣市的區，用戶勾選 | 一個主要行政區 |
| **個性** | 系統提供選項，用戶勾選 | 友善／怕生／活力／慢熱 |
| **時段** | 系統提供選項，用戶勾選 | 清單最多顯示 **3** 個 |
| **地點** | 用戶自行輸入（公園名、常見出沒處等），掛在已選行政區下 | 清單最多顯示 **3** 個 |
| **簡短介紹** | 用戶自行輸入 | **50 字內** |

### 個性（系統選項）
友善／怕生／活力／慢熱

不做：高齡、幼犬。清單上看不到個性；點進主人詳情才顯示。

### 時段（系統選項）
兩軸勾選，組合成出沒時段。只分**平日／假日的早、中、晚**：

- **日型：** 平日、假日
- **時段：** 早、中、晚

例：平日早、假日晚。清單最多顯示 3 個時段；超過則建立時限制或只露出前 3 個。

鄰汪夥伴可用這套時段勾選篩選。沒勾＝全部；有勾＝時段有重疊才顯示。

### 地點
用戶自行輸入建立地點（例：中央公園、凹子底森林公園）。不把行政區名稱當成清單上的公園名；行政區來自所在縣市的即時 API，公園名是用戶填的地點。清單最多顯示 3 個地點。精確集合點仍等雙方 Connect 成功後才給，不露住家。

## 頁面流程

未訂閱可看清單；**主人詳情、Connect／聊天、創辦／報名汪汪聚會都要有效訂閱**（創始 100 人已是永久免費訂閱）。免費註冊＝手機號＋狗檔案同時完成。對方也必須接受才能開始聊。

```
探索（清單免費，無需訂閱）
  ├─ 鄰汪夥伴（目前所在縣市；可用時段篩選：平日／假日 × 早／中／晚）
  └─ 範例汪汪
        → 排序：出去次數高→低；相同則資料豐富程度高→低
        → 清單卡：照片、時段（最多 3）、地點（最多 3）、出去次數
              → 點進去（需訂閱）：主人詳情（含個性、簡短介紹）＋ Connect 按鈕
                    → Connect 成功：顯示見面提醒
                    → 對話窗（需 Connect：對方也接受才能開始聊天；最多 20 句；送出＝小飛機 icon）
                          → 雙方自己約細節、自己見面

聚會（原「我的」）
  └─ 該市汪汪聚會（依主辦人汪汪大隊長分數高→低）
        → 報名（需訂閱）→ 個人頁看得到參加的聚會
              → 點進去：LINE 群組邀請

個人頁（探索／聚會右上角）
  ├─ 創辦汪汪聚會（必須附 LINE 群組連結）
  ├─ 參加的聚會
  ├─ Connect 邀請（待回覆／已送出／已接受／歷史）
  └─ 聊天列表（右滑刪除）
```

未訂閱點 Connect／報名／創辦 → 訂閱頁。v1 引導去右上角填手機號＋狗檔案佔名額（不必驗證碼）。v2 改 Apple 內購；未訂閱仍可看詳情與邀請。

### 探索首頁
- **不做**「依地點／依時間／主人清單」分頁。
- **鄰汪夥伴**可用時段**勾選**篩選（平日／假日 × 早／中／晚；可複選）。沒勾＝全部；有勾＝時段有重疊才顯示。
- 可用該市行政區縮小範圍。不可切到其他縣市。
- 清單含**範例汪汪**（團團／可可），每位登入用戶都看得到。
- 所有探索清單同一套**排序**（見下方；範例汪汪置頂、不參與該區皇冠）。

### 範例汪汪＋新手教學

兩筆範例汪汪（團團／可可），不綁縣市，所有人看得到。

登入並完成狗檔案後，進入**新手教學 tour**：
1. 要求用戶 Connect **團團** → 團團**一定會回**（立刻接受）並主動傳訊息。
2. 再請用戶**嘗試 Connect 可可** → 可可也會回並主動傳訊息。
3. 介紹汪汪聚會後結束教學。

兩筆範例汪汪都會在 Connect 成功後主動傳訊息。可略過教學，但範例汪汪仍留在清單上。

### 汪汪聚會

聚會頁列出**目前所在縣市**的汪汪聚會。未訂閱可預覽聚會卡；報名、創辦需有效訂閱。額滿不可再報。

**誰可以創辦**
- 在**個人頁**創辦（右上角進入個人頁）。
- 必須附上 **LINE 群組連結**，沒有連結不能建立。

**聚會簡介欄位**

| 欄位 | 規則 |
|------|------|
| **名字** | 必填，**10 字內** |
| **日期** | 必填 |
| **地點** | 必填 |
| **類型** | 必選其一：趣味競賽／野餐／散步／動物餐廳／動物咖啡廳／爬山／單身狗 |
| **收費** | **0／50／100／200／自訂**。請主辦者根據活動類型決定收費 |
| **簡介** | **50 字內** |
| **LINE 群組連結** | 必填；報名後在個人頁點進該場聚會可看到邀請 |

平台不經手報名費、不做金流託管。收費只是主辦者標示給參加者看。

**報名之後**
- 該場聚會出現在**個人頁 → 參加的聚會**。
- 點進去可以看到 **LINE 群組邀請**（主辦者建立時附上的連結）。
- 活動結束後，參加者可以給主辦人**按讚**；**一人一場活動只能按一次**。

**活動列表排序**
- 以**一個市**為單位（目前所在縣市）。
- 主辦人的**汪汪大隊長分數**越高，顯示越上面。
- 分數相同則較早建立的在前。

### 清單卡（長條形）

所有探索清單同一套橫列卡，**不是**大方塊／網格。

**清單上只顯示**
- **照片：** 大頭貼。**必須是狗主人與狗的合照**（兩者都要入鏡）；只放狗、只放主人、或無法辨識者不通過、不上清單
- **時段：** 最多 **3** 個（系統選項：平日／假日 × 早／中／晚）
- **地點：** 最多 **3** 個
- **出去次數**
- 名字（狗名為主；可附主人暱稱）仍可放在卡上當識別，但**不顯示個性**

**清單上不顯示**
- 個性（點進去才看）
- Connect 次數（點進去才看）
- Connect 按鈕（點進去才有）
- 簡短介紹（點進去才看）
- 汪汪大隊長次數／汪汪隊員次數／汪汪大隊長分數（個人頁／詳情才看）

整列可點進主人詳情（未訂閱則改引導訂閱，不開詳情）。

### 清單排序

鄰汪夥伴（不含置頂範例汪汪）同一套排序：

1. **出去次數**由高到低（雙方都按「已見面」才算的那個數）。
2. 出去次數相同 → **個人資料豐富程度**由高到低。
3. 豐富程度仍相同 → 先註冊者在前。

**個人資料豐富程度**（用來比序，不在清單上顯示分數）

每填一項加分；沒填不加。分數只用於排序。

| 項目 | 分數 |
|------|------|
| 合照通過審核（主人＋狗都入鏡） | 3 |
| 品種／混種 | 1 |
| 體型 | 1 |
| 年齡區間 | 1 |
| 個性：每勾 1 個標籤 | 1（最多 4） |
| 時段：每勾 1 組 | 1（最多以清單露出的 3 組計） |
| 地點：每建立 1 個地點 | 1（最多 3） |
| 簡短介紹 | 1 |
| 與其他狗（已選一項） | 1 |
| 行政區已選（來自所在縣市 API） | 1 |

沒有檔案或合照未過審 → 不上清單，不參與排序。

**特效框：新用戶**
- 剛註冊、尚未完成第一次「雙方互按已見面」的主人，清單卡外框有**新用戶特效框**（例如柔光描邊／閃爍，與一般卡明顯不同）
- 第一次出去次數 +1 後拿掉特效框，之後不再顯示

**皇冠：該區出去次數前三名**
- 以**目前所在行政區**的出去次數排名（同分時 Connect 次數高者在前；再同分則先註冊者在前）
- 該區第 1／2／3 名，清單卡上依序顯示**金／銀／銅皇冠**
- 只在「該區」清單顯示該區排名；切到同市別區時不沿用他區皇冠。探索本身不跨縣市。
- 範例汪汪不佔該區皇冠。
- 新用戶特效框與皇冠可並存
- 皇冠是該區徽章，**不改**上面的清單排序規則

### 主人詳情（從清單點進去）

需有效訂閱才 Connect（創始 100 人已具備）。v2 未訂閱可看詳情，按 Connect 才進訂閱頁。

訂閱後可看：
- 照片（主人＋狗合照）
- **簡短介紹**（50 字內）
- 狗的類型（品種／混種、體型）
- **個性**（系統選項勾選結果；清單上看不到）
- 時段（系統選項：平日／假日 × 早／中／晚）
- 地點（模糊到區域，不露住家）
- 兩個配對數值：**出去次數**、**Connect 次數**
- 三個聚會數值：**汪汪大隊長次數**、**汪汪隊員次數**、**汪汪大隊長分數**
- **Connect 按鈕**
- **檢舉／封鎖**（真人檔案；範例汪汪沒有）

詳情頁**不再放規則卡**。見面提醒只在 Connect 成功時顯示一次。

精確集合點要等雙方 Connect 成功後才給。

### Connect 與對話窗
- 從主人詳情按 **Connect 按鈕** 發出邀請；對方在**個人頁**看到邀請並接受後，才能開始聊天。單方送出不算開始。
- 雙方都必須有效訂閱（創始永久免費也算）才能發起或接受。
- 聊天最多 **20 句**（雙方合計）。滿了就不能再送，之後改由雙方自行約。
- 輸入列送出改成類似 LINE 的**小飛機 icon**，不要用「送」字按鈕。
- Connect 成功後解鎖：簡易聊天＋精確集合點（若有填）。
- **每次 Connect 成功時**顯示見面提醒（一段文字，見下）。檔案上不再勾規則卡。
- 雙方自己約細節、自己見面、自己善後。
- 個人頁的聊天列表可**右滑刪除**該對話。

建議預設文案（非強制行程）：**公園平行走 15 分鐘**（兩狗牽繩、保持距離）→ 雙方覺得 OK 再靠近。第一次不當成「放繩對玩」。

平台**不**做：進行中狀態機、GPS 軌跡、結束必傳照片才解鎖、每場 LINE Pay。

### 見面提醒（Connect 成功時才顯示）

取代規則卡。不當場監控；違規靠檢舉。

見面提醒：雙方主人請全程在場。第一次請約公共公園，不要約私人庭院或室內。全程牽繩，直到雙方口頭同意才靠近。體型差大時預設平行走、不互相撲。若任一方的狗出現壓力訊號（躲、吠、低吼、身體僵硬），立刻拉開並結束當次。合照需當下口頭同意；夜間不要用閃光燈直射眼睛。現場怎麼走由你們自己決定。

### 個人頁（右上角進入）

Connect 邀請、聊天列表、創辦／參加的聚會都集中在**個人頁**，不另外做獨立 inbox 當主入口。底部分頁不再放「我的」。

**免費註冊＝手機號＋狗檔案同時完成。** 沒有狗檔案就不算註冊成功，不能只佔白名單空號。

個人頁可見：
- **創辦汪汪聚會**（必須附 LINE 群組連結；欄位見上）
- **參加的聚會：** 報名後看得到；點進去看 LINE 群組邀請；活動結束後可給主辦人按讚（一人一場一次）
- **待回覆：** 別人對我發出的 Connect（接受／拒絕）
- **已送出：** 我對別人發出、對方尚未回覆
- **已接受／歷史：** 成功 Connect 與過去紀錄
- **聊天列表：** 可右滑刪除
- 自己的狗檔案、出去次數、Connect 次數
- **汪汪大隊長次數、汪汪隊員次數、汪汪大隊長分數**
- 訂閱狀態（含是否為創始永久免費）

未訂閱進入個人頁 → 直接引導訂閱。不做「先看邀請再付費才接受」。

## 核心流程 — 狗狗交友

讓主人依出沒時段找到附近有狗的主人，約戶外見面。重點是配對與溝通，不是行程管理。可另辦汪汪聚會，報名後進 LINE 群組。

### 探索（搜尋附近主人）

| 篩選 | MVP |
|------|-----|
| **縣市** | 定位即時判定；僅用戶目前所在縣市。試用四市以外不開 |
| **行政區** | 不寫死；即時 API **只抓該縣市的區**。篩選與「該區」皇冠用這份清單 |
| **地點** | 用戶建立的地點（掛在該市行政區下）。不露住家。清單最多顯示 3 個地點 |
| **時間** | **鄰汪夥伴**用**勾選**篩選（平日／假日 × 早／中／晚）。不做依時間分頁 |
| **鄰汪夥伴** | 目前所在縣市的主人。可用該市行政區、時段勾選。長條形橫列：照片、時段（最多 3）、地點（最多 3）、出去次數；**排序：出去次數 → 資料豐富程度**；新用戶特效框；該區出去次數前三名依序金／銀／銅皇冠。個性與 Connect 按鈕在點進去後才出現 |
| **範例汪汪** | 團團／可可，不綁縣市，所有人看得到 |
| **汪汪聚會** | 在**聚會**頁；該市列表；依主辦人汪汪大隊長分數高→低。個人頁可創辦（必附 LINE 群組連結） |
| **體型** | 小型／中型／大型；體型差兩級要警示（大狗嚇到小狗） |
| **個性** | 系統選項：友善／怕生／活力／慢熱。建立時勾選；**僅詳情頁顯示**，清單不顯示 |
| **能否與其他狗互動** | 可一起玩／需慢熱牽繩平行走 |
| **簡短介紹** | 50 字內；僅詳情頁 |
| **信用／門檻** | 清單看出去次數；詳情另看 Connect 次數。發起 Connect 需有效訂閱 |

## 見面確認與信用

完成見面後**可選**上傳照片＋互評（不擋繼續使用）。

**出去次數（硬規則）**
- 必須**雙方都按「已見面」**才 +1。單方按、只互評、只上傳照片都不算出去次數。

**加分／展示（可選）**
- 準時、完成見面（雙方已互按）
- 上傳現場照（簡單審核：戶外、有狗、無違規）
- 對方給正面評價

**扣分／凍結**
- 放鳥、遲到嚴重、違規解繩／強行靠近對方的狗、未經同意拍照／傳播
- 被檢舉且成立 → 扣分；嚴重則暫停 Connect 權

**展示**
- 清單：照片、時段（最多 3）、地點（最多 3）、出去次數；新用戶特效框；該區出去次數前三名金／銀／銅皇冠。排序：出去次數 → 資料豐富程度
- 詳情／個人頁：出去次數 + Connect 次數 + 汪汪大隊長次數 + 汪汪隊員次數 + 汪汪大隊長分數 + 個性 + 簡短介紹 + 近期評價摘要（若有）
- 低於門檻不可發起 Connect

## 金流：訂閱制（MVP）

**原則：** 第一版不抽單場佣金、不做 C2C 託管。營收來自**訂閱**。Connect 成功後雙方自行溝通與見面。汪汪聚會收費由主辦者標示（0／50／100／200／自訂），平台不經手。

同一帳號狀態：**創始永久免費**／**訂閱中**／**未訂閱**。前兩者都算有效訂閱。沒有 payer／payee 場次帳本、沒有幫忙者錢包、沒有銀行提領。

### 誰付錢
| 意圖 | 錢怎麼走 |
|------|----------|
| 看探索清單（鄰汪夥伴、時段勾選、範例汪汪；照片、最多 3 時段、最多 3 地點、出去次數）與聚會頁預覽 | 免費 |
| 建立／編輯狗檔案（個人資料） | 免費註冊當下必須完成；v2 未訂閱也可建／編 |
| 看主人詳情（含個性、介紹、Connect 次數、汪汪大隊長／隊員數值）、發起／接受 Connect、解鎖聊天（最多 20 句）與集合點、互評、創辦／報名汪汪聚會 | 需有效訂閱 |
| 見面現場／汪汪聚會收費 | 平台不經手；禁止引導私下當成「平台託管」 |

### 訂閱內容

- **免費（未訂閱）：** 只看清單。不可看詳情、不可 Connect、不可報名聚會。
- **有效訂閱後：** 看主人詳情、發起／接受 Connect、解鎖精確集合點、對話窗（最多 20 句）、互評、創辦／報名汪汪聚會。
- **創始 100 人：** 試用期寫入白名單的前 100 個 `login_key`（手機號＋狗檔案，不驗證碼）。下次升級後白名單視為已事先訂閱，不必再付。權限與付費訂閱相同。
- 雙方都需有效訂閱才能聊天（避免一方付費、另一方白嫖溝通）。
- 第 101 人起（v2）可建檔、看詳情、看邀請；要主動 Connect／接受聊天／聚會一律先訂閱（Apple 內購）。已付費可對未訂閱發邀請。

### 付款
- **v1 不收款。** 只靠創始白名單 100 人。iOS 不可用 LINE Pay／外部金流解鎖 Connect、聊天、聚會報名（Apple 3.1.1）。
- **v2：** App Store 走 **In-App Purchase** 自動續訂月繳；白名單內不必付。Android 若上架再對 Google Play Billing。
- LINE Pay 不做為 App 內數位功能的付款方式。
- 付不了內購（且不在白名單）→ 無法主動 Connect／接受聊天／聚會報名與創辦。
- 週期自動續訂；取消後用到該期結束。創始永久免費沒有取消到期這件事。
- 特店／公司戶等收款資格等 v2 再開。

### 不做（刻意砍掉）
- 每場代遛／一起遛的授權 → 請款 → 託管 → 90% 撥出
- 錢包、提領 KYC、最低提領額
- 取消／放鳥的分帳規則（放鳥只影響信用，不涉及退款拆帳）
- 汪汪聚會收費走平台金流（改由主辦者標示，參加者自行處理；報名後進 LINE 群組）

## 資訊架構
```
探索（清單免費；僅目前所在縣市）
  ├─ 右上角 → 個人頁
  ├─ 鄰汪夥伴（可用時段篩選：平日／假日 × 早／中／晚）
  └─ 範例汪汪
        → 排序：出去次數 → 資料豐富程度
        → 長條清單（照片／時段最多 3／地點最多 3／出去次數；新用戶特效框；該區前三皇冠）
              → 主人詳情（需訂閱：介紹／個性／類型／時段／地點／配對數值／聚會數值）＋ Connect 按鈕
                    → Connect 成功 → 見面提醒
                    → 對話窗（最多 20 句；送出＝小飛機 icon）＋集合點
                          → 自己見面
                                → 雙方互按「已見面」→ 出去次數 +1

聚會（原「我的」；該市；依主辦人汪汪大隊長分數高→低）
  ├─ 右上角 → 個人頁
  └─ 汪汪聚會卡
        → 報名（需訂閱）
              → 個人頁「參加的聚會」
                    → LINE 群組邀請
                    → 活動結束後給主辦人按讚（一人一場一次）→ 汪汪大隊長分數 +1

個人頁（探索／聚會右上角進入；免費註冊＝手機號＋狗檔案同時完成）
  ├─ 創辦汪汪聚會（名字 10 字／日期／地點／類型／收費／簡介 50 字／LINE 群組連結）
  ├─ 參加的聚會
  ├─ Connect 邀請（待回覆／已送出／已接受／歷史）
  ├─ 聊天列表（右滑刪除）
  ├─ 狗檔案（縣市＝定位；行政區＝該市即時 API；個性／時段系統選；地點自填；介紹 50 字）
  ├─ 出去次數／Connect 次數
  ├─ 汪汪大隊長次數／汪汪隊員次數／汪汪大隊長分數
  ├─ 訂閱（白名單已事先訂閱／未訂閱；v1 不收款）
  └─ 刪除帳號
```

## 冷啟動
試用四市可進（高雄、台南、新北、台北），但每人當下只看到**自己所在縣市**（外加範例汪汪）。行政區不寫死，定位後即時 API 只抓該市。密度靠創始白名單 100 人先把檔案填實（填手機號＋狗檔案，不驗證碼），**檔案與 Connect 寫在 Supabase**，換機同一支號碼仍在。範例汪汪負責第一個 Connect 與第一句訊息，降低空城感。地點由用戶填、掛在該市行政區下；時段用平日／假日 × 早／中／晚填實。汪汪聚會在個人頁創辦、聚會頁依該市大隊長分數排列；報名後進 LINE 群組。清單把出去次數高、檔案填得完整的人排前面，鼓勵先出門、先把資料補齊。下次升級打開訂閱牆時，這 100 個 `login_key` 已在白名單，不必再付費。
